## Overview

MusicChain becomes more valuable with every new participant. This chapter maps the feedback loops that create compounding growth.

## Four loops

### Loop 1 — Supply

```
More Artists → More Music → More Discovery → More Listeners → More Artists
```

### Loop 2 — Data

```
More Listeners → Better Discovery Data → Smarter Recommendations → Higher Satisfaction → More Listeners
```

### Loop 3 — Quality

```
Better Artists → Better Reputation → Better Discovery → Better Artists
```

### Loop 4 — Community

```
More Community → More Ratings → Better TFPS → Better Discovery → More Community
```

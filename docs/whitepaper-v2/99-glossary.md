| **MCIP** | MusicChain Improvement Proposal |
| **Music Discovery Law** | Every authentic interaction should increase the probability that the next great artist is discovered |
| **Successful discovery** | Normative event (MCIP-0009): first contact with artist + deep listen or qualifying follow-up |
| **TFPS** | Track Field Pressure System; momentum and community pulse metric |
| **UserChain** | Trust and reputation ledger derived from authentic participation |

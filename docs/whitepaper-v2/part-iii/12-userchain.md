## Overview

UserChain is the trust and reputation layer — a derived ledger that records every meaningful action and composes it into a reliability field.

## Planned sections

Daily trust state per user, derived from triad roles.

### 12.2 Actions that build trust

```
Listen + Like + Comment + Share + Report + Support
                    ↓
              Trust Score
```

Trust is earned gradually through consistent, positive participation.

### 12.3 Trust-weighted signals

High-trust users' discovery actions carry more weight in TFPS and recommendations.

### 12.4 Anti-fraud integration

Bot detection, device fingerprinting (private), trust decay for suspicious patterns.

### 12.5 UserChain and the Music Discovery Law

Reliable reputation makes discovery recommendations more trustworthy.
